# buffer-scripts

Scripts and tools for managing and generating Buffer posts for **The Arkansas Echo**.

This repo helps automate and organize content for the Facebook, YouTube, TikTok, and other channels connected through Buffer.

## Current Focus
- Arkansas Black history posts (Little Rock Nine, Daisy Bates, Sister Rosetta Tharpe, Maya Angelou, Hot Springs Echo, etc.)
- Consistent scheduling (currently two Facebook posts per day)
- Source tracking and credit formatting

## Planned Scripts
- `generate_post.py` – Template for drafting history posts with sources
- `schedule_helper.py` – Helpers for timing and channel selection
- Future: API helpers if Buffer API access expands

## How to use
1. Clone the repo
2. Add your own scripts or edit the templates
3. Keep sources accurate and local to Arkansas history
